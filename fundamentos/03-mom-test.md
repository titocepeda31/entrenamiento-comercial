# Aprendizajes de The Mom Test

Guía original de estudio inspirada por Rob Fitzpatrick, *The Mom Test* (2013). No es una traducción.

El foco es **preguntar por conductas y experiencias reales**, no buscar elogios ni validación de una solución ya construida.

## Preguntas comparadas
| Menos útil | Más útil |
|---|---|
| «¿Le gustaría mi sistema de reservas?» | «¿Cómo anotaron las reservas de ayer?» |
| «¿Comprarían una automatización?» | «¿Qué ocurre la última vez que se acumularon consultas?» |
| «¿Le serviría una web nueva?» | «¿Qué querían lograr con su web actual?» |
| «¿Le gustó mi idea?» | «¿Qué han intentado antes para resolverlo?» |

## Secuencia útil
1. Entender cómo lo hacen hoy.
2. Pedir un ejemplo reciente.
3. Preguntar qué consecuencia tuvo.
4. Investigar qué alternativa usan y qué han intentado.
5. Comprobar si realmente desean invertir atención, tiempo o dinero para cambiarlo.

No confundir entusiasmo verbal («interesante») con compromiso. Una reunión con fecha, revisión autorizada o prueba acordada ofrece una señal más verificable.

## Precisión comercial
Si un comprador terminó en otra tienda porque le respondieron al día siguiente, se puede afirmar que hubo respuesta tardía y que compró fuera. No puede garantizarse que responder antes habría producido una venta propia.
